# Tea House 🌿🍵

**Tea House** is a modern and visually appealing website for a tea and botanical solutions supplier. It showcases featured products, highlights unique qualities of the brand, and keeps users engaged with news, events, and client testimonials.  

---

## 🔗 Live Demo

Check out the live website here: [Tea House Live](https://hoqueeprobal.github.io/tea-house/)

---

## 🖥 Features

- **Responsive Design:** Works seamlessly on mobile, tablet, and desktop devices.  
- **Hero Banner:** Attractive hero section with a call-to-action button.  
- **Featured Products:** Grid layout showcasing popular teas with hover animations.  
- **Client Testimonials:** Creative testimonial section with layered card effects.  
- **News & Events:** Highlights latest updates and promotions.  
- **Footer with Newsletter & Social Links:** Easy user interaction and subscription options.  
- **Tailwind CSS & Font Awesome:** Modern styling and icons for a clean UI.  

---

## 🛠 Technologies Used

- HTML5  
- CSS3 (Custom + Tailwind CSS)  
- Font Awesome (icons)
